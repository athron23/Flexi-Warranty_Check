# Serial Desk

เว็บเก็บ Serial Number ของร้านคอมพิวเตอร์ ใช้รับสินค้าเข้า ขายออก และเช็คประกัน รองรับเครื่องยิงบาร์โค้ดแบบ USB/บลูทูธ

- ไฟล์หน้าเว็บ: `serial-desk.html` (ไฟล์เดียว ไม่มี build)
- ลิงก์หน้าที่เผยแพร่แล้ว: https://claude.ai/artifact/Rv9vyACKhByVLVUSYNxL2R
- เวอร์ชันล่าสุดตอนส่งมอบ: 3

## วิธีแก้ไขต่อในอนาคต

1. เปิดแชทใหม่กับ Claude แล้วแนบ `serial-desk.html` พร้อมลิงก์ด้านบน
2. บอกสิ่งที่ต้องการแก้ และขอให้ "แก้แล้วเผยแพร่ทับลิงก์เดิม"
3. ต้องเผยแพร่ทับลิงก์เดิมเสมอ ข้อมูลสต็อกผูกกับลิงก์นี้ ถ้าสร้างลิงก์ใหม่ ข้อมูลเดิมจะไม่ตามไป

## ข้อมูลที่เก็บ (ฐานข้อมูลของหน้านี้)

| ที่เก็บ | เนื้อหา |
|---|---|
| `units/{SERIAL}` | สินค้าหนึ่งชิ้นต่อหนึ่ง Serial |
| `settings/warranty` | ระยะประกันตั้งต้นตามประเภท `{defaults: {ประเภท: เดือน}}` |
| `settings/lists` | ประเภทที่ร้านเพิ่มเอง `{categories: [...]}` |

ฟิลด์ใน `units`: `serial`, `product`, `brand`, `category`, `supplier`, `warrantyMonths`, `status` (`in_stock` หรือ `sold`), `receivedAt`, `soldAt`, `customer`, `phone`, `invoice`, `warrantyEnd` (รูปแบบ YYYY-MM-DD), `example`

รหัสเอกสารคือ Serial ตัวพิมพ์ใหญ่ ตัวอักษรที่ฐานข้อมูลไม่รับจะถูกแปลงเป็น `~` ตามด้วยเลขฐานสิบหก

## ความสามารถที่ประกาศไว้

`db` (เก็บข้อมูลร่วมกัน), `downloads` (ส่งออก CSV), `user` (ตรวจสิทธิ์เขียน)

## หมายเหตุ

- ระยะประกันนับจากวันที่ยิงขายออก
- ค่าตั้งต้นระยะประกันตามประเภทเป็นค่าโดยประมาณ ให้ร้านแก้ตามเอกสารผู้จำหน่ายจริง
- ลิงก์เช็คประกันทางการมีเฉพาะ ASUS, Lenovo, HP, Dell, Acer, MSI (อยู่ใน `BRANDS` ในสคริปต์)
- ยังไม่มี: ประกันตลอดอายุ, ลบหรือแก้ชื่อประเภทที่เพิ่มเอง, พิมพ์สติกเกอร์บาร์โค้ด
- ข้อมูลตัวอย่างมีฟิลด์ `example: true` ล้างได้จากปุ่มในหน้าเว็บ
